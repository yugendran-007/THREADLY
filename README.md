# THREADLY — Customized T-Shirt Designing & Online Ordering Website

A complete, modern, front-end-only fashion e-commerce mini project. Customers can browse
T-shirts, design their own in a live design studio, add items to a shopping bag, apply
discount codes, check out, and track their orders.

> **This is a college mini-project demonstration.** It is built entirely with HTML, CSS and
> vanilla JavaScript. There is **no backend** and **no real payment** processing. All data
> is stored in the browser's LocalStorage on your own device.

---

## 1. Tech Stack

| Layer      | Technology |
|------------|------------|
| Structure  | HTML5 (semantic, accessible) |
| Styling    | CSS3 (custom design system, CSS variables, flexbox & grid) |
| Behaviour  | Vanilla JavaScript (ES5-compatible, modular IIFEs) |
| Storage    | `localStorage` (cart, wishlist, orders, saved designs, preferences) |
| Graphics   | Inline SVG + SVG-generated mockups, HTML5 Canvas (design studio) |
| Fonts      | Google Fonts — Inter, Poppins (+ Bebas Neue, Playfair, Pacifico in the studio) |
| Icons      | Inline SVG icon set (works fully offline) |

**No** React, Node.js, Express, MongoDB, Bootstrap or Tailwind is used.

**Theme:** black + neon green. The palette is driven by CSS variables in `css/style.css`
(`--c-accent: #00e676`, `--c-bg-alt: #000000`, dark surfaces), so the whole site re-themes
from that single token block. The home hero features a hand-drawn SVG cartoon boy wearing a
custom-printed tee (generated by `boySVG()` in `js/data.js`).

## 2. How to Run (VS Code + Live Server)

1. Install [Visual Studio Code](https://code.visualstudio.com/).
2. Install the **Live Server** extension (by Ritwick Dey) from the Extensions marketplace.
3. Open the project folder in VS Code:
   `Customized T-Shirt Designing and Ordering Website`
4. Right-click **`index.html`** in the file explorer → **"Open with Live Server"**.
5. Your browser opens at something like `http://127.0.0.1:5500/index.html`.

> You can also just double-click `index.html` to open it directly in a browser — everything
> still works, because the project uses **no** fetch/AJAX calls.

Recommended browser: the latest Chrome, Edge or Firefox.

## 6. Important Notes (Honesty & Limitations)

- **No backend.** Contact messages and newsletter sign-ups are validated in the browser
  and stored locally only — they are **not** emailed or sent anywhere.
- **No real payments.** The "Demo Online Payment" option only marks the order as paid in
  the demo. No card details are collected.
- **Tracking is simulated.** Real courier tracking would require a shipping-provider API
  and a server. The demo advances statuses manually.
- **LocalStorage is not a database.** It is fine for a demo but is not secure, is limited
  in size (~5 MB) and is specific to your browser/device.
- All product images, prices, reviews and contact details are **fictional demonstration
  data**.
